# BirdWatcher

AI-powered bird-feeder camera that complements a Haikubox (audio bird-ID) with vision-based detection and species classification.

- **Camera**: Reolink RLC-811WA (4K, WiFi, varifocal) → motion-event JPGs + MP4 clips pushed via FTPS
- **Backend**: FastAPI on a small cloud VM. Tiled YOLO11-small detection → per-bird IoU tracking → sharpness-aware multi-frame crop selection → EfficientNet-B2 species classifier (allow-list filtered) → Bayesian fusion with Haikubox audio prior + seasonal prior → multi-crop voting
- **Frontend**: Vite/React/TS PWA with Web Push for rare-species notifications, infinite-scroll feed, searchable species picker including a "Not a bird" sentinel for active-learning false-positive labels
- **Host**: `birdwatcher.ryanhoulette.com`

## Development

```bash

cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

## Future improvements

Stashed here so they don't drift away. Numbered by how soon they should happen.

### 1. Active-learning fine-tune (waiting on data)

`scripts/retrain_classifier.py` is a stub. Once ~50 user corrections per real species accumulate via the in-feed picker (current count: ~26 across all species, plus ~210 "Not a bird" labels), wire it up to do a real LoRA / head-only fine-tune of `dennisjooo/Birds-Classifier-EfficientNetB2`. The YOLO false-positive problem is closer to data-feasible than the species head — the "Not a bird" labels alone might be enough for a YOLO classifier-head fine-tune now.

### 2. Classifier upgrade (deferred — current bottleneck is image quality)

`scripts/benchmark_classifiers.py` compared the current `dennisjooo/Birds-Classifier-EfficientNetB2` against `prithivMLmods/Bird-Species-Classifier-526` (SigLIP-2 backbone) on our labeled-correction set. The SigLIP-2 model was ~4× better at top-1 (14 % vs 3 %) but both are poor in absolute terms because the feeder-cam crops are blurry / small / motion-blurred. We're keeping dennisjooo and focusing on improving image quality (multi-frame voting from MP4 + sharpness ranking, see `pipeline/process.py::_rank_detections`) before re-running the A/B.

iNaturalist 2021 checkpoints (1,486 species, real citizen-science photos) remain interesting but would need a non-trivial HF wrap.

### 3. Scheduled yard calibration refresh

`yard_priors.json` is regenerated by hand (`scripts/calibrate_from_haikubox.py`). Schedule monthly via APScheduler so the priors track seasonal population shifts without manual intervention.

### 4. Audio-correlation backfill

The Haikubox poller only fetches the last hour, so backlogged visits never get audio confirmation. A daily 24-hour-window pull would let recently-processed detections benefit from contemporaneous audio.

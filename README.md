# BirdWatcher

AI-powered bird-feeder camera that complements a Haikubox (audio bird-ID) with vision-based detection and species classification.

- **Camera**: Reolink RLC-811WA (4K, WiFi, varifocal) → motion-event clips pushed via HTTP
- **Backend**: FastAPI on a small cloud VM. YOLO11-nano detection → per-bird IoU tracking → EfficientNetV2 (NABirds) species classifier → Bayesian fusion with Haikubox audio prior + seasonal prior → multi-frame voting
- **Frontend**: Vite/React/TS PWA with Web Push for rare-species notifications
- **Host**: `birdwatcher.ryanhoulette.com`

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

## Future improvements

Stashed here so they don't drift away. Revisit once the camera is producing real footage and we have ground truth to benchmark against.

### Classifier swap (deferred)

The current classifier is `dennisjooo/Birds-Classifier-EfficientNetB2`, an EfficientNet-B2 trained on the 525-species `gpiosenka` Kaggle dataset, post-filtered via the eastern-NA allow-list in `pipeline/classify.py`. It correctly recognizes Northern Cardinal at 0.87–1.00 on smoke-test footage but missed White-throated Sparrow entirely in the same video.

Two candidate replacements worth benchmarking on real RLC-811WA footage:

- **`prithivMLmods/Bird-Species-Classifier-526`** — SigLIP-2 backbone (2024), same 525-species lineage. A newer, stronger backbone for fine-grained tasks; same training-data limitations though. Probably a 30-min swap once we have real ground truth.
- **iNaturalist 2021 dataset checkpoints** — 1,486 birds, real citizen-science photos (closer to feeder-cam distribution). No drop-in HF transformers package exists; would need a research checkpoint wrap. Significantly more work, but potentially a much bigger gain on fine-grained sparrow / warbler / finch IDs.

Decide between them only after collecting ~50 labeled feeder-cam crops via the Phase 6 active-learning UI; that's the only honest evaluation set.

### Yard calibration refresh cadence

`yard_priors.json` is regenerated by hand (`scripts/calibrate_from_haikubox.py`). Once the system is live, schedule this to run monthly via APScheduler so the priors track seasonal population shifts without manual intervention.
